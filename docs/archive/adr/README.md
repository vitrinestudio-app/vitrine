# Architecture decision records (historical)

These records (0000–0032, with their amendments) are **historical** and
superseded by [`ARCHITECTURE.md`](../../../ARCHITECTURE.md) on 2026-11-13.
They are kept unchanged for the reasoning, research and measurements behind
the decisions; they may describe behaviour the code no longer has.

- What holds today: `ARCHITECTURE.md`. Its §14 "Decision index" has one row
  per ADR number (decision, status current / partly / superseded, section),
  so references like "ADR 0029" in code comments and docs resolve there.
- New decisions: update the relevant section of `ARCHITECTURE.md` and add a
  row to its decision log (§15); numbering continues after its last row (0033 = ARCHITECTURE.md itself). No new files
  here.
- `images/` holds the spike images ADR 0001 and 0003 link.
- The German concept they refer to as `docs/KONZEPT.md` is archived next
  door as [`../KONZEPT-de.md`](../KONZEPT-de.md).
