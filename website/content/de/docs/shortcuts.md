Dieselbe Liste gibt es in der App: Drück <kbd>?</kbd> (nicht beim Tippen),
klick auf **?** in der unteren Leiste oder wähle ☰ → *Tastatur & Maus …*.
Unter Windows und Linux ist <kbd>⌘</kbd> <kbd>Strg</kbd> und <kbd>⌥</kbd>
<kbd>Alt</kbd>. Auf dem Trackpad wirkt Scrollen mit zwei Fingern wie das
Mausrad.

## Navigation & Zoom {#navigation--zoom}

| Taste / Geste | Aktion |
|---|---|
| Scrollen | Ansicht nach oben und unten verschieben (Trackpad: in jede Richtung) |
| <kbd>Umschalt</kbd> + Scrollen | Ansicht seitwärts verschieben |
| <kbd>⌘</kbd> + Scrollen, Zwei-Finger-Zoom | um den Mauszeiger herum vergrößern und verkleinern |
| Ziehen auf einer leeren Fläche | Ansicht verschieben (in jeder Ansicht) |
| <kbd>Leertaste</kbd> + Ziehen, mit mittlerer Taste ziehen | Ansicht verschieben |
| Rollbalken | ziehen verschiebt die Ansicht (erscheinen, wenn der Inhalt nicht passt) |
| <kbd>⌘</kbd><kbd>+</kbd> / <kbd>⌘</kbd><kbd>−</kbd> | vergrößern / verkleinern |
| <kbd>⌘</kbd><kbd>0</kbd> | an Fenster anpassen |
| <kbd>⌘</kbd><kbd>1</kbd> | Originalgröße (Export-Pixel) |

## Auswählen {#selecting}

| Taste / Geste | Aktion |
|---|---|
| Klick | Element auswählen (eine Gruppe als Ganzes) |
| Doppelklick | Element innerhalb seiner Gruppe auswählen (ein Text öffnet sich zum Bearbeiten) |
| Doppelklick auf freie Seitenfläche | Hintergrund-Element der Seite auswählen |
| <kbd>⌘</kbd> + Klick | Element unter dem Mauszeiger direkt auswählen, auch innerhalb einer Gruppe |
| <kbd>Umschalt</kbd> + Klick | zur Auswahl hinzufügen oder aus ihr entfernen |
| <kbd>Umschalt</kbd> + Ziehen auf einer leeren Fläche | mit einem Rahmen auswählen (ergänzt die Auswahl) |
| <kbd>⌘</kbd><kbd>A</kbd> | alle Elemente der Leinwand auswählen (nicht die gesperrten) |
| <kbd>Esc</kbd> | Auswahl aufheben oder laufendes Ziehen abbrechen |

## Verschieben & Anordnen {#moving--arranging}

| Taste / Geste | Aktion |
|---|---|
| Element ziehen | verschieben (rastet an Seitenrändern, Mitten und anderen Elementen ein) |
| <kbd>Umschalt</kbd> beim Verschieben | nur waagerecht oder senkrecht |
| <kbd>⌥</kbd> beim Verschieben oder Skalieren | kein Einrasten |
| <kbd>Umschalt</kbd> an einem Größen-Anfasser | Seitenverhältnis beibehalten (nicht bei Texten) |
| Dreh-Anfasser | drehen (rastet bei 0°, ±5°, ±15°, ±45°, ±90° ein) |
| <kbd>Umschalt</kbd> beim Drehen | freier Winkel in 0,1°-Schritten |
| Pfeiltasten | Auswahl um 1 lu verschieben |
| <kbd>Umschalt</kbd> + Pfeiltasten | Auswahl um 10 lu verschieben |
| <kbd>⌘</kbd><kbd>C</kbd> / <kbd>⌘</kbd><kbd>X</kbd> / <kbd>⌘</kbd><kbd>V</kbd> | Elemente kopieren, ausschneiden, einsetzen (Einsetzen über den Originalen = versetzte Kopien) |
| <kbd>⌘</kbd><kbd>D</kbd> | duplizieren |
| <kbd>⌘</kbd><kbd>G</kbd> | gruppieren |
| <kbd>⇧</kbd><kbd>⌘</kbd><kbd>G</kbd> | Gruppierung aufheben |
| <kbd>⌫</kbd>, <kbd>Entf</kbd> | Auswahl löschen |
| <kbd>[</kbd> / <kbd>]</kbd> | eine Ebene nach hinten / nach vorn |
| <kbd>Umschalt</kbd>+<kbd>[</kbd> / <kbd>Umschalt</kbd>+<kbd>]</kbd> | ganz nach hinten / ganz nach vorn |
| <kbd>⌘</kbd><kbd>Z</kbd> | widerrufen |
| <kbd>⇧</kbd><kbd>⌘</kbd><kbd>Z</kbd>, <kbd>⌘</kbd><kbd>Y</kbd> | wiederholen |
| Rechtsklick | Kontextmenü: auf einem Element (Ausschneiden, Kopieren, Einsetzen, Anordnen, Sperren, Ausblenden …) oder auf einer leeren Fläche (auf dieser Seite einsetzen, alles auf dieser Seite auswählen) |
| <kbd>Umschalt</kbd>+<kbd>F10</kbd>, Menütaste | Kontextmenü der Auswahl |
| Dateien auf ein Gerät ablegen | sein Screenshot für die aktuelle Sprache |
| Dateien anderswo ablegen | Import-Dialog (Screenshots, Bilder, Schriften) |

## Texte bearbeiten {#editing-texts}

| Taste / Geste | Aktion |
|---|---|
| Doppelklick auf einen Text der Leinwand | in der aktuellen Sprache bearbeiten |
| <kbd>Enter</kbd> | übernehmen (Klick daneben übernimmt auch) |
| <kbd>Umschalt</kbd>+<kbd>Enter</kbd> | Zeilenumbruch |
| <kbd>Esc</kbd> | Bearbeiten abbrechen |
| <kbd>⌘</kbd><kbd>Enter</kbd> | Textfeld im Inspektor übernehmen |
| Klick, <kbd>Enter</kbd> | Übersetzungstabelle: Zelle bearbeiten (<kbd>Enter</kbd> übernimmt, <kbd>Umschalt</kbd>+<kbd>Enter</kbd> bricht um, <kbd>Esc</kbd> bricht ab) |

## Inspektor & Ebenen {#inspector--layers}

| Taste / Geste | Aktion |
|---|---|
| Beschriftung eines Zahlenfelds seitwärts ziehen | Wert ändern (<kbd>Umschalt</kbd>: größere Schritte) |
| <kbd>↑</kbd> / <kbd>↓</kbd> | in einem Zahlenfeld: einen Schritt hoch / runter |
| <kbd>Umschalt</kbd>+<kbd>↑</kbd> / <kbd>Umschalt</kbd>+<kbd>↓</kbd> | in einem Zahlenfeld: größere Schritte |
| <kbd>Enter</kbd> | eingegebenen Wert übernehmen |
| <kbd>Esc</kbd> | eingegebenen Wert verwerfen |
| <kbd>Umschalt</kbd> + Klick | Ebenen: einen Bereich auswählen |
| <kbd>⌘</kbd> + Klick | Ebenen: zur Auswahl hinzufügen oder entfernen |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Ebenen: nächste / vorige Ebene auswählen |
| Doppelklick, <kbd>Enter</kbd>, <kbd>F2</kbd> | Ebenen: umbenennen |
| Ziehen | Ebenen: Reihenfolge ändern |
| Ziehen, Doppelklick | Inspektor: linken Rand ziehen ändert die Breite (Doppelklick: Standard) |
| Klick, <kbd>Enter</kbd> | Bilder und Screenshots: Klick öffnet die Vorschau |
| <kbd>←</kbd> / <kbd>→</kbd> | Vorschau: vorheriges / nächstes Bild |

## App & Dialoge {#app--dialogs}

| Taste / Geste | Aktion |
|---|---|
| <kbd>?</kbd> | diese Übersicht (nicht beim Tippen) |
| <kbd>⌘</kbd><kbd>N</kbd> | neues Projekt |
| <kbd>⌘</kbd><kbd>O</kbd> | Projekt öffnen |
| <kbd>⌘</kbd><kbd>E</kbd> | exportieren |
| <kbd>⌘</kbd><kbd>,</kbd> | App-Einstellungen |
| <kbd>Esc</kbd> | Dialog schließen |
| <kbd>Enter</kbd> | Rückfrage bestätigen |
| Projektordner auf den Startbildschirm ziehen | öffnen |
| <kbd>⌥</kbd> + Rechtsklick | eigenes Kontextmenü der Web-Ansicht (zur Fehlersuche) |

Unter macOS stehen die Menüeinträge der App auch in der Menüleiste
(*Vitrine Studio*, *Ablage*, *Bearbeiten*, *Fenster*, *Hilfe*). Während du in
einem Textfeld tippst, macht <kbd>⌘</kbd><kbd>Z</kbd> dein Tippen rückgängig;
sonst die letzte Änderung am Projekt.
